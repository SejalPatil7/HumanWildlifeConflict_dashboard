# Himalayan Human–Wildlife Conflict Dashboard

> AI-powered monitoring and visualization of human–wildlife conflict incidents across the Indian Himalayan Region (2020–2026)

## Project Overview

Human–wildlife conflict is one of the most significant conservation challenges across the Indian Himalayan Region. Reports of bear attacks, leopard attacks, snow leopard livestock depredation, wolf attacks, crop raiding, and elephant conflict are published daily across regional news outlets, making it difficult for conservation researchers to monitor incidents at scale.

This project builds an **end-to-end AI pipeline** that automatically collects wildlife conflict news, extracts structured information and full article text using GPT-4o Mini, and visualizes the resulting dataset through an interactive Streamlit dashboard.

**Developed for:** Nature Conservation Foundation (NCF) — High Altitude Program

---

## Features

- Automated, targeted collection of public wildlife conflict news using Google News RSS — queries are built from species × conflict-event × region combinations rather than a generic search.
- AI-powered classification and structured-field extraction from headlines using GPT-4o Mini.
- Clean, boilerplate-free full article body extraction for every confirmed incident.
- Interactive Streamlit dashboard with filters.
- Geographic visualization of incidents across Himalayan states.
- Timeline and hotspot analysis.
- Downloadable filtered dataset.

## Data Collection Methodology

### Step 1 — Targeted News Collection

`crawler/query_builder.py` builds search queries from combinations of:

- **Species** (13 region-relevant species)
- **Conflict-event phrasing** specific to that species (e.g. "livestock" for predators, "crop raiding" for crop-raiders)
- **Region** (Ladakh, Kashmir, Jammu, Himachal Pradesh, Uttarakhand) — only regions each species actually occurs in

This produces high-precision queries like `"Asian Elephant crop raiding Uttarakhand"` or `"Snow Leopard kills sheep Ladakh"` instead of broad generic searches, cutting down on irrelevant results.

`crawler/scrape.py` runs these queries against Google News RSS and collects:

- Headline
- Source
- URL
- Publication Date

### Step 2 — AI Classification & Field Extraction

`extractor/extract.py` sends candidate headlines (after a keyword pre-filter) to GPT-4o Mini in batches, which:

- Classifies whether the headline describes a genuine HWC incident
- Extracts structured fields: date, state, district, species, conflict type, human injuries/deaths, livestock losses, summary, confidence score

### Step 3 — Article Body Extraction

For every confirmed incident, `extractor/body_extractor.py`:

- Resolves the Google News redirect link to the real publisher URL
- Extracts just the clean article body text (via `trafilatura`, with a `newspaper3k` fallback) — no navigation, ads, related-article links, or other boilerplate

### Step 4 — Data Cleaning

The dashboard automatically:

- Normalizes state names.
- Normalizes wildlife species.
- Removes non-Himalayan incidents.
- Infers missing districts from headlines.
- Removes duplicate incidents.

## Running the Project

### 1. Collect Headlines

```bash

python scrape.py
```

```bash

python extract.py
```

```bash
cd dashboard
streamlit run app.py
```

```text

```

## Limitations

- Uses publicly reported news articles only.
- Media coverage does not represent every conflict incident.
- District coordinates are approximated for visualization.
- Missing locations are inferred from headlines where possible.
- Duplicate reporting is partially removed.
- Article body extraction depends on publisher site structure and may fail or return partial text for some sources.
